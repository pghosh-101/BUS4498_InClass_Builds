# Job Application Writing Rules

> **SYNTHETIC teaching example.** These are assumed writing preferences for this Skill, not an employer’s policy, legal guidance, or verified research.

- Prioritize requirements explicitly marked as required in the job posting. Treat preferred qualifications as secondary unless the user says otherwise.
- Use the job posting’s terminology when it accurately describes the user’s experience. Do not add keywords that the user cannot support.
- Write resume bullets with a clear action, relevant context, and a verified result when one is available.
- Use numbers, dates, tools, titles, and outcomes only when supplied or confirmed by the user.
- If evidence is missing, write `[NEEDS CONFIRMATION]` or ask a focused question. Never fill the gap with a plausible detail.
- Keep the tone direct, professional, specific, and consistent with the user’s requested voice.
- For cover letters, connect the user’s experience to the role instead of using generic praise about the company.
- For application questions, answer the question directly before adding supporting context.
- Before returning materials, check for unsupported claims, inconsistent dates or titles, keyword stuffing, repeated points, and length or formatting requirements.
